# MSK-CHORD (Nature 2024)

This repository provides access information and licensing details for the clinical and DNA data associated with the **MSK-CHORD** study published in *Nature* (2024) by Memorial Sloan Kettering Cancer Center (MSK).

## Data Access
All clinical and DNA sequencing data for the MSK-CHORD cohort are publicly accessible via **cBioPortal**.

* **Study Link:** [MSK-CHORD (Nature 2024) on cBioPortal](https://www.cbioportal.org/study/summary?id=msk_chord_2024)
